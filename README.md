# Prompt Builder — สร้าง Prompt ภาพ/วิดีโอ AI

เว็บแอปภาษาไทยสำหรับช่วยประกอบ Prompt ภาษาอังกฤษและภาษาไทย เพื่อนำไปใช้กับเครื่องมือสร้างภาพนิ่งและวิดีโอด้วย AI พร้อมรองรับการติดตั้งเป็นแอป (PWA) และเปิดใช้งานออฟไลน์หลังจากโหลดแอปสำเร็จอย่างน้อยหนึ่งครั้ง

## ความสามารถ

- เลือกประเภทงาน **ภาพนิ่ง** หรือ **วิดีโอ**
- กรอกวัตถุ/ตัวละคร ฉาก และรายละเอียดเพิ่มเติม พร้อมปุ่มเติมรายละเอียดด่วน
- เลือกสไตล์ 44 แบบ ครอบคลุมคอนเทนต์ การถ่ายภาพ/ภาพยนตร์ การ์ตูน/ศิลปะ และแนวคิด/บรรยากาศ
- กำหนดอัตราส่วนภาพ ความละเอียด ระยะเวลาวิดีโอ มุมกล้อง การเคลื่อนกล้อง แสง และโทนสี
- เลือก Negative Prompt และเพิ่มข้อความที่ต้องการหลีกเลี่ยงเอง
- ตั้งค่าเสียงบรรยาย น้ำเสียง Caption ตำแหน่ง และแม่แบบบทพูด
- สร้างผลลัพธ์ Prompt ทั้งภาษาอังกฤษและภาษาไทย พร้อมปุ่มคัดลอกแยกส่วนและคัดลอกด่วน
- สลับธีมสว่าง/มืด โดยจดจำค่าธีมไว้ในเบราว์เซอร์
- ติดตั้งเป็นแอปบนอุปกรณ์ที่รองรับ และเปิดหน้าแอปแบบออฟไลน์ได้หลังจากเข้าใช้งานครั้งแรก

## โครงสร้างไฟล์

```text
prompt-builder-pwa/
├── index.html                 # แอปหลัก (HTML, CSS และ JavaScript)
├── manifest.webmanifest       # ชื่อแอป สี ไอคอน และการตั้งค่า PWA
├── sw.js                      # Service Worker และระบบแคชออฟไลน์
├── favicon.svg                # Favicon สำหรับเบราว์เซอร์
├── icons/
│   ├── icon-192.png           # ไอคอน PWA 192×192
│   ├── icon-512.png           # ไอคอน PWA 512×512
│   ├── icon-maskable-512.png  # ไอคอนสำหรับ Maskable display
│   └── apple-touch-icon.png   # ไอคอนสำหรับ iOS/iPadOS
├── .nojekyll                  # ป้องกัน GitHub Pages ประมวลผลไฟล์ด้วย Jekyll
└── .github/workflows/
    └── deploy.yml             # Workflow สำหรับ Deploy ไป GitHub Pages
```

## ทดลองใช้งานบนเครื่อง

ไม่ควรเปิด `index.html` ด้วย `file://` โดยตรง เพราะ Service Worker ต้องทำงานผ่าน HTTPS หรือ localhost

ใช้ Python เปิดเว็บเซิร์ฟเวอร์จากโฟลเดอร์โปรเจกต์:

```bash
python -m http.server 8000
```

จากนั้นเปิด `http://localhost:8000` ใน Chrome, Edge หรือเบราว์เซอร์ที่รองรับ

## วิธีนำขึ้น GitHub และเผยแพร่ด้วย GitHub Pages

1. สร้าง Repository ใหม่บน GitHub เช่น `prompt-builder-pwa`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ไปไว้ที่ root ของ Repository
3. ตรวจสอบว่าไฟล์ Workflow อยู่ที่ `.github/workflows/deploy.yml`
4. Push ไปยัง branch `main` (Workflow ตั้งค่าเริ่มต้นให้ Deploy เมื่อมีการ push ไป `main`)
5. เข้า **Settings → Pages** ของ Repository แล้วตั้ง **Build and deployment → Source** เป็น **GitHub Actions**
6. เปิดแท็บ **Actions** และตรวจสอบ Workflow ชื่อ **Deploy Prompt Builder to GitHub Pages** ว่าทำงานสำเร็จ
7. เข้า URL ที่ GitHub Pages แสดงในหน้า Settings → Pages

> หากใช้ branch ชื่ออื่น ให้แก้ `branches: ["main"]` ใน `.github/workflows/deploy.yml` ให้ตรงกับ branch ที่ใช้งาน

GitHub Pages ให้บริการผ่าน HTTPS ซึ่งจำเป็นต่อการติดตั้ง PWA และการทำงานของ Service Worker

## วิธีติดตั้งแอป

- **Android / Chrome หรือ Edge:** เปิด URL ของเว็บ แล้วกดปุ่ม **ติดตั้งแอป** บนหน้าเว็บ หรือเลือกเมนูเบราว์เซอร์ → ติดตั้งแอป
- **คอมพิวเตอร์ / Chrome หรือ Edge:** กดปุ่มติดตั้งบนหน้าเว็บ หรือใช้ไอคอนติดตั้งในแถบที่อยู่/เมนูเบราว์เซอร์
- **iPhone / iPad:** เปิดเว็บไซต์ด้วย Safari → แตะปุ่ม Share → เลือก **Add to Home Screen (เพิ่มไปยังหน้าจอโฮม)**

หมายเหตุ: เบราว์เซอร์จะแสดงหน้าต่างติดตั้งอัตโนมัติเฉพาะเมื่อผ่านเงื่อนไขของเบราว์เซอร์และแพลตฟอร์มนั้น ๆ ปุ่มติดตั้งในแอปจะแสดงคำแนะนำสำหรับกรณีที่ไม่มีหน้าต่างติดตั้งแบบ Native

## การใช้งานออฟไลน์และการอัปเดต

- เปิดเว็บไซต์ขณะออนไลน์อย่างน้อยหนึ่งครั้ง เพื่อให้ Service Worker เก็บไฟล์หลักลง Cache
- เมื่อกลับมาเปิดแอปโดยไม่มีอินเทอร์เน็ต หน้าแอปและฟังก์ชันสร้าง Prompt หลักยังใช้งานได้
- ฟอนต์ IBM Plex Sans Thai ที่โหลดจาก Google Fonts อาจไม่พร้อมใช้งานเมื่อออฟไลน์ หากยังไม่เคยถูกแคชไว้ ระบบจะใช้ฟอนต์สำรองของอุปกรณ์แทน
- เมื่อแก้ไขไฟล์แอปและต้องการบังคับให้เบราว์เซอร์ใช้แคชชุดใหม่ ให้เปลี่ยนค่า `CACHE_NAME` ใน `sw.js` เช่น `prompt-builder-pwa-v1.0.1` แล้ว Deploy ใหม่

## ข้อจำกัดและความเป็นส่วนตัว

- แอปนี้เป็นเว็บแอปฝั่ง Client ไม่ต้องใช้ฐานข้อมูลหรือ Backend
- ข้อความที่กรอกในฟอร์มและ Prompt ที่สร้าง **ไม่ได้ถูกบันทึกถาวร** เมื่อรีเฟรชหน้าอาจสูญหาย ควรคัดลอกผลลัพธ์เก็บไว้ก่อนออกจากหน้า
- มีการเรียก Google Fonts เพื่อโหลดฟอนต์เมื่อเชื่อมต่ออินเทอร์เน็ต แอปหลักไม่ส่ง Prompt ไปยังบริการ AI ภายนอก
- การคัดลอกใช้ Clipboard API เมื่อเบราว์เซอร์อนุญาต และมีวิธีสำรองสำหรับบางกรณี

## การปรับแต่ง

- แก้ข้อความ ตัวเลือก และตรรกะการประกอบ Prompt ได้ใน `<script>` ภายใน `index.html`
- แก้สีชื่อแอปและค่าเริ่มต้น PWA ได้ที่ `manifest.webmanifest`
- เปลี่ยนไอคอนโดยแทนที่ไฟล์ใน `icons/` และ `favicon.svg`
- หากเปลี่ยนชื่อหรือโฟลเดอร์แอปบน GitHub Pages ให้คง path แบบ relative (`./`) ใน manifest และการลงทะเบียน Service Worker เพื่อรองรับ Repository Pages
